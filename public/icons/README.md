# App icons

Made from two 1024 px source images on a magenta background (keyed out to transparency):

- **Detailed book** → `logo.png` (full size), `icon-512.png`, `icon-192.png` (sidebar, spine seal, PWA; `icon-512.png` doubles as the maskable icon),
  `apple-touch-icon.png` (180 px). All transparent: an opaque background shows up as a dark tile on the home screen.
- **Pixel-art book** → `../favicon.ico` (16/32/48/64 px) and `favicon-32.png`; it stays readable at tab size.
